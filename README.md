# Monkey Quest Reborn Wiki

Player wiki for Monkey Quest on MQReborn: game mechanics, items, zones, quests, the world map and a build calculator

Live site: https://whyvnaa.github.io/Monkey-Quest-Reborn-Wiki/

This repository only holds the built website (GitHub Pages serves it from `main`). It is generated: don't edit
files here, they are replaced on every build. Monkey Quest art © Nickelodeon, MQ Reborn logo © the MQReborn team.

To preview it locally, run this in this folder and open http://localhost:8000/:

```bash
python -m http.server 8000
```
